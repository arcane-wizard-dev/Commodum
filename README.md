# Commodum

[![GitHub Release](https://img.shields.io/github/v/release/arcane-wizard-dev/Commodum?color=blue&logo=github&cacheSeconds=600)](https://github.com/arcane-wizard-dev/Commodum/releases) [![GitHub Release Date](https://img.shields.io/github/release-date/arcane-wizard-dev/Commodum?color=blue&logo=github&cacheSeconds=600)](https://github.com/arcane-wizard-dev/Commodum/releases)

_Less clicking. More playing._

Commodum is a World of Warcraft addon that simplifies everyday gameplay with optional quality-of-life improvements. It takes care of routine actions and allows parts of the interface to be adapted to personal preferences.

> ⚠️ **Important!** This addon requires **Arcane Wizard: Library**. See Installation & Quick Start for installation details.

## Key Feature

**Quality of Life Tweaks** - Offers individually selectable conveniences with configurable behavior that make everyday interactions with the game more comfortable.

## Features

Individual features and display options can be configured in the addon settings. Commodum supports an account profile and character profiles.

### User Interface

* Uses the 24-hour clock for the in-game time display and automatically reapplies the setting after login/UI reload to work around a known Blizzard UI issue.
* Automatically shows the faction whose reputation just changed on the reputation bar.
* Hides loot notifications for items, gold, and personal currencies, each separately.\*

*\* This feature is only available in Retail.*

### Merchant Actions

* Automatically repairs all damaged items using personal funds when a repair merchant window opens.
* Automatically sells sellable poor-quality (gray) items from the bags when a merchant window opens; locked items are skipped.
* Automatically sells items marked with a modifier key + right-click at merchants; locked and unsellable items are skipped.

## Supported Languages & Flavors

* Languages: English, German, Russian
* Flavors: Forever, Retail

## Installation & Quick Start

> **Required Dependency:** This addon requires **Arcane Wizard: Library**. If you install Commodum via the CurseForge client, the library will be downloaded automatically. If you install the addon manually, via Wago, or through another third-party updater that does not resolve dependencies, you must download and enable the library separately.

To manage the addon, type the following commands in chat and press Enter:

* Type `/com` or `/commodum` to access the addon options menu.
* Type `/com changelog` or `/commodum changelog` to open the changelog.
